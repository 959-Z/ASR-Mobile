# Day 3 Benchmark CSV Template

This template matches the Android benchmark CSV generated by the app.
Use it for manual notes if the CSV cannot be pulled from the device immediately.

## CSV Header

```csv
timestamp,run_index,device,android_version,abi,model_name,quantization,model_path,model_size_mb,audio_file,audio_duration_s,load_time_ms,inference_time_ms,rtf,java_heap_delta_mb,native_heap_delta_mb,transcript,quality_score,notes
```

## Field Meaning

| Field | Meaning | Unit / Format |
|---|---|---|
| timestamp | Benchmark time | `yyyy-MM-dd HH:mm:ss` |
| run_index | Repeat run number | `1`, `2`, `3` |
| device | Android device name | manufacturer + model |
| android_version | Android OS version | text |
| abi | CPU ABI | e.g. `arm64-v8a` |
| model_name | Human-readable model name | e.g. `Whisper Tiny` |
| quantization | Quantization level inferred from filename | `Q8`, `Q5`, `Q4`, `FP16`, `unknown` |
| model_path | Runtime model path | app storage path |
| model_size_mb | Model file size | MB |
| audio_file | Test audio file | filename |
| audio_duration_s | Audio duration | seconds |
| load_time_ms | Model loading time | milliseconds |
| inference_time_ms | Transcription time | milliseconds |
| rtf | Real-time factor | inference time / audio duration |
| java_heap_delta_mb | Java heap change during inference | MB |
| native_heap_delta_mb | Native heap change during inference | MB |
| transcript | ASR output text | text |
| quality_score | Manual quality score | 1-5 |
| notes | Failure cases or observations | text |

## Manual Quality Score

| Score | Meaning |
|---:|---|
| 5 | Almost completely correct |
| 4 | Minor errors, meaning is complete |
| 3 | Main meaning is understandable, but errors are obvious |
| 2 | Only part of the content is recognized |
| 1 | Mostly unusable |

## Minimum Day 4 Rule

- Run each model and audio pair 3 times.
- Use the same audio for all models in one comparison group.
- Keep units consistent: MB, ms, s, RTF.
- Add manual `quality_score` and `notes` after reading the transcript.
